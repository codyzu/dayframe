# Dayframe

A household dashboard for a browser-based photo frame: morning weather, family photos, scheduled display modes, and later household integrations.

**Based on Wes Bos's work in [photo-frame-dashboard](https://github.com/wesbos/photo-frame-dashboard).** His dashboard and Android frame research are the starting reference for implementation. Dayframe adapts that work to the requirements below; compatibility with the Dragon Touch Classic 10 remains to be verified.

- [Implementation plan, upstream sources, and milestones](docs/implementation-plan.md)
