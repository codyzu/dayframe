# F03 local synthetic display evidence — 28 October 2026

Generated by the photo/offline Playwright suites in Chromium at 1280 × 800
(Standard and Large) and mobile WebKit emulating iPhone 13. These are browser
fixtures, not physical-frame or phone acceptance. Gray photo backgrounds are the
minimal synthetic WebP used by offline tests; the admin image is canvas-generated.
No household photos, identities, settings or device data are included.

- `quiet-*`: normal online playback with a partially saved collection, no routine
  persistence/sync text; reduced motion enabled in the focused quiet cases.
- `offline-*`: saved playback with concise offline status, retry and existing controls.
- `denied-*`: observed authorization denial clears photo pixels and exposes reconnect.
- `empty-*`, `failure-*`: useful empty/unavailable messages without sync chatter.
- `storage-unavailable-*`: online photo remains usable with an offline-copy warning.
- `expired-fallback-*`: no private pixels after lease expiry; reconnect remains usable.
- `administration-*`: keyboard-opened local diagnostics, with persistence, progressive
  synchronization, eviction and backup caveats scoped to the current browser.

Reviewed normal/partial-sync, offline, empty, denied, expired, failure and admin
screenshots. Narrow-screen controls were moved below clock/weather after the first
review exposed overlap; final mobile screenshots and geometry assertions show
separate control, retry, status and mode-navigation rows. Existing native maintenance
is untouched. See the implementation-plan delivery record for checks/release scope.
