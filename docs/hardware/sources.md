## Primary platform sources

- [Official Mozilla Firefox 143.0.4 ARMv7 APK](https://archive.mozilla.org/pub/fenix/releases/143.0.4/android/fenix-143.0.4-android-armeabi-v7a/fenix-143.0.4.multi.android-armeabi-v7a.apk): host download, SHA-256, binary manifest and ABI verified. Local APK signature verification remains a pre-installation gate.
- [Android ADB guide](https://developer.android.com/tools/adb): host transport and installation reference. Modern wireless pairing instructions do not describe the frame's legacy root TCP daemon.
- [Linux-sunxi FEL](https://linux-sunxi.org/FEL): Boot ROM USB mechanism and board/entry caveats. Documentation is not proof that our port/board supports a usable restore procedure.
- [Linux MMC boot partitions](https://www.kernel.org/doc/html/latest/driver-api/mmc/mmc-dev-parts.html): boot-area representation and write-protection behavior; Classic enumeration still needed.
- [Linux ext4 superblock fields](https://www.kernel.org/doc/html/latest/filesystems/ext4/super.html): supports investigation of mutable live filesystem metadata, not a blanket exception for mismatches.
- [Mozilla GeckoView overview](https://firefox-source-docs.mozilla.org/mobile/android/geckoview/): self-contained engine vs system WebView.
- [GeckoView ContentDelegate Javadocs](https://mozilla.github.io/geckoview/javadoc/mozilla-central/org/mozilla/geckoview/GeckoSession.ContentDelegate.html): painted-content lifecycle research; current documentation is newer than pinned 143. Verify actual 143 APIs/artifact before writing the kiosk.
