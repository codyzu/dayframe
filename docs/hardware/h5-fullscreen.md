**Inference, not a captured boot-clock trace:** Firefox starting before the device clock synchronizes is consistent with these near-epoch timestamps and the later correct clock. Current [Mozilla cookie validation code](https://raw.githubusercontent.com/mozilla-firefox/firefox/main/netwerk/cookie/Cookie.cpp) adjusts future creation/access timestamps during database load; current main is research, not proof of the exact 143.0.4 boot sequence.
